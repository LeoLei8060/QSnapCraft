# QSnapCraft
基于Qt的快速、高效的截图工具。
![example](./ReadMe_res/example.gif)

## 构建要求

- Qt 6.7.2 或更高版本
- MSVC 2019 或更高版本
- CMake 3.24 或更高版本
- Windows 10/11 操作系统

## 项目结构

```
QSnapCraft/
├── src/                    # 源代码目录
│   ├── app/               # 应用启动与窗口协调
│   ├── capture/           # 截图请求、选区与会话
│   ├── config/            # 配置模型与持久化
│   ├── output/            # 复制、保存与贴图输出
│   ├── paint/             # 标注场景与图元
│   ├── pinboard/          # 贴图窗口
│   ├── platform/windows/  # Windows 平台能力
│   └── ui/                # 工具条、覆盖层、设置和托盘
├── resources/             # 资源文件
└── CMakeLists.txt        # CMake构建配置
```
